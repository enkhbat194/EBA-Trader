- exact single-use authorization for `sfv2-discovery-pilot-v1`;
- existing 406-candidate / 12-strata / inspected-D0 identities frozen in config;
- bounded local production runner with the shared checkout lock;
- deterministic pre-result D0 survivor policy;
- automatic immutable survivor or zero-survivor freeze only after all 4,872 trials are terminal;
- root-side research-maintenance integration;
- sanitized read-only `/api/research/status` visibility;
- external exact-build completion proof;
- focused regression/safety tests;
- updated project-state/TODO decision record.

- Frozen OOS access;

A D0 survivor is still only a discovery nomination. Zero survivors is a valid result.
